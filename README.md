# Neon Air Hockey

Браузерная мини-игра Air Hockey.

## Режимы
- Игрок против бота
- Два игрока на одной клавиатуре

## Управление
- Игрок 1: W A S D
- Игрок 2: стрелки
- P: пауза
- R: сброс счёта

Побеждает первый, кто забьёт 7 голов.

Открой index.html в браузере или опубликуй репозиторий через GitHub Pages.
